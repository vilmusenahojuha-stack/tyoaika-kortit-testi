# Testit

Aja Node.js-ympäristössä:

```sh
node tests/worktime-regression.test.js
```

Testi tarkistaa JavaScript-syntaksin, käyttöliittymän DOM-viittaukset, v27-välimuistin,
PWA-kuvakkeen, suojauskäytännön, uuden Sheets-osoitteen, aikavyöhykkeet,
taukovähennyksen ja käyttäjäkohtaisen offline-jonon.
